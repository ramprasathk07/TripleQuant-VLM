### 7. **OCR DATASET BLOCKER — ROOT CAUSE FOUND + FIXED**  (was pending A/B)
Probed `linxy/LaTeX_OCR`:
- Columns are `image`, **`text`** (NOT `formula`).
- Multi-config: `default`=train-only; **`full`/`small`/`synthetic_handwrite`** have
  train/validation/**test**.
- `load_dataset('linxy/LaTeX_OCR', None, split=...)` **raises** — config name REQUIRED.
  This (no config passed + wrong split=test on a train-only default) = the actual
  "all OCR metrics broken" cause.

- eval path: registry pins `"config": "full"`; `eval_ocr` threads `subset` →
  `load_hf_dataset(subset=...)`. schema `ocr_subset` + benchmark passes it.
- **calibration path (same trap, also broken):** `llm_compressor._get_calibration_dataset`
  now `load_dataset(name, subset, split=...)` reading new `CalibrationConfig.subset`;
  error msg lists available configs+splits.
- All 10 VLM quant configs patched: `subset: full` added, `text_field: formula → text`.
- `utils.load_latex_ocr` fixed (subset="full", doc cols image/text).
